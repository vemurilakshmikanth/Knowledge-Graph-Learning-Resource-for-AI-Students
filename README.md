# 📝 Knowledge Graph - Learning Resource for AI Students

A Natural Language Processing project that extracts knowledge from AI-related text using NLTK and builds a knowledge graph using RDF ontology, which can then be queried using SPARQL.

---

## 🧪 Techniques Used
- Sentence Tokenization & Word Tokenization
- POS Tagging (Part of Speech)
- Regex Chunking to extract Noun Phrases
- RDF Knowledge Graph Construction
- Ontology Integration (.ttl file)
- SPARQL Querying on Knowledge Graph

---

## 🛠️ Libraries Used
| Category | Tools |
|---|---|
| Language | Python 3 |
| NLP | NLTK |
| Knowledge Graph | RDFLib |
| Ontology | OWL / Turtle (.ttl) |
| Environment | Google Colab |

---

## 🚀 How to Run
```bash
pip install nltk rdflib pydotplus graphviz
```
Open the `.ipynb` file in Jupyter Notebook or Google Colab and run cells sequentially.
